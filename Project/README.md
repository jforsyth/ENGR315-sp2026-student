## Project Summary & Background

This project focuses on a dataset revolving around car crashes in New York City. This data was gathered in order to try and get closer to the Vision Zero goal, which is to eliminate traffic fatalities. The Dataset includes variables about crashes such as injuries, fatalities, location, timestamps, number of cars involved, and reason the crash occurred. Using this data, helpful conclusions can be drawn based on the information that tells us why these driving fatalities may be happening. These conclusions could then be used by third party sources, such as law enforcement, to help further eliminate some of the dangerous driving activity.

In this project we aim to answer the following questions about the dataset. 
- How have crashes trended over the years?
- What is historically the most dangerous time and place to drive in NYC?​
- ​What is the most common contributing factor across all accidents?​

These were questions that we felt would be useful to know in the pursuit of the Vision Zero Goal. Our project answers these questions graphically, using numerical methods in python to extract the desired information from the data set.
